# Smile Constructions — maquette du site

Deux versions du site de Smile Constructions (tous travaux du bâtiment en Occitanie) :

- `jaune.html` : version jaune, dans l'esprit de la carte de visite ;
- `blanc.html` : version blanche, maison en plein écran ;
- `index.html` : page de choix entre les deux.

Pages statiques (HTML, CSS, JavaScript), sans compilation. Publiées avec GitHub Pages.

- Images : illustrations générées, à remplacer par les photos des chantiers.
- Carte de l'Occitanie : contour des départements simplifié depuis github.com/gregoiredavid/france-geojson (données IGN / OpenStreetMap, licence ouverte).
- Maison 3D : three.js 0.147 (chargé depuis jsDelivr).
- Le questionnaire de contact n'envoie rien pour l'instant : à relier à la boîte mail de l'entreprise.
- Les pages portent `noindex` (maquette) : à retirer à la vraie mise en ligne.
